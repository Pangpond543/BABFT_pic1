# BABFT Pic 1

Python ย่อขนาดรูปภาพ 32x32px และแปลงค่าสี RGB 32สี เป็นเลข Binaly 5 bit ส่งข้อมูลสีไปให้ในเกมในรูปแบบการกดปุ่มบนคีย์บอร์ด
(RGB แบ่งเป็น R 4 ระดับ G 4 ระดับ และ B 2 ระดับ = 4x4x2 = 32สี)
(ใช้ปุ่ม z,x,c,v,b แทนการส่งเลข 5 bit และ h เป็นตัว สั้งให้ไป px ถัดไป)
